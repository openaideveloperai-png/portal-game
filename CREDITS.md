# Credits

## Third-party assets

**Characters and animation — Quaternius** ([quaternius.com](https://quaternius.com)), CC0 1.0
- Universal Base Characters (male and female bodies, hair, beard, skin textures)
- Universal Animation Library and Universal Animation Library 2 (idles, walks, sitting,
  talking, carrying, folding arms, leaning on a rail and more)
- Mannequin bodies (the Reference Persons)

Obtained from the GitHub mirror `NafisRayan/Animate-Rigged-Humanoid-No-Blender` and converted
by `tools/build-assets.mjs` (unused data removed, rotations quantised, meshes simplified for
distant mannequins, textures re-encoded). Clothing is painted onto the bodies at run time.
